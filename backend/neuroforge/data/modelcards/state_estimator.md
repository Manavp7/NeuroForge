# Model Card — Patient State Estimator

**Type:** Bagged Ridge regression ensemble (scikit-learn).
**Purpose:** Infer latent patient-state constructs (neuroinflammation, dopaminergic/serotonergic
deficit, pain, mood, seizure risk) from multimodal features, with uncertainty.

- **Inputs:** synthetic proteomics, genomics risk scores, wearable summaries, labs, EEG band powers.
- **Outputs:** per-construct value + 1-sigma uncertainty; overall confidence; feature attributions.
- **Training data:** synthetic patients generated by NeuroForge (ground-truth latent known).
- **Uncertainty:** bootstrap-ensemble disagreement, inflated by EEG artifact ratio / low SNR.
- **Limitations:** trained only on the synthetic generator's distribution; not validated on real
  patients; correlations are hand-designed, not learned from clinical cohorts.
- **NOT intended for:** any clinical, diagnostic, or treatment decision. Simulation/demo only.
